使用提示与兼容性 ＋

iPhone / iPad：建议使用 Safari，点击连接并允许“运动与方向”。Android：使用支持方向传感器的浏览器。请通过 HTTPS 地址打开；内置浏览器无法连接时，请用系统浏览器打开。

连接后保持舒适握姿，模型正面朝向你。需要更换参照方向时点击“设为正面”；横竖屏切换会重新校准。模型按物理方向跟随，不作镜像反转。演示模式不使用真实传感器数据。

静止时更新频率降低是正常的省电行为。“距最近采样”是数据新鲜度，不是端到端延迟。实际响应取决于浏览器及设备；方向读数可能漂移，可重新校准。
